Lemon Launcher: Duck Hunt
Run:   cd lemon-duck-game && python3 -m http.server 8000   then open http://localhost:8000/ in Chrome.
(Opening index.html directly via file:// will not work because ES modules need a web server.)
Controls: mouse = look (click to lock pointer), left click / Space = launch lemon, WASD = walk (Shift = faster),
R = reload (auto when empty), Esc or P = pause, M = mute. Touch devices: drag to look, joystick to walk, lemon button to fire.
